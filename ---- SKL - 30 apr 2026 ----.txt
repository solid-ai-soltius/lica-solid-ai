------------

1. table dashboard - header

id doc, tipe, vendor / cust, nilai, status, ingest date (tanggal upload), update date



2. table review ocr - detail

id doc, base64_pdf, akurasi (confidence), nama perusahaan, tipe, tanggal (yg ada di dalam pdf, yg udh di scan oleh LICA), customer, alamat, total nilai, no po.ref, tgl kirim

di label review ocr, kan ada pt sumber jaya, nah ini ambil dari data kolom customer

dan ini bisa di edit

kalo udh klik btn approve, maka di table header, dari menunggu review -> approved


workflow dari yitshak, yg akan menentukan status awal di table header, threshold confidence / akurasi = 95%
akurasi >= 95 ---> status = 'menunggu review'
akurasi < 95 ---> status = 'antrian manual' dan Ketika di menu review ocr, div card edit, menjadi merah, dan low nya juga merah. baru Ketika udah di edit dan ada btn tambahan yaitu 'yakin?' dan Ketika mereka pilih yakin, maka warna merah nya lama lama jadi putih, karena ada banyak kolom yg harus mereka edit
contoh ada 10 kolom low semua => card edit bg warna merah bgt
lalu di edit, jadi misal 9 kolom low dan 1 kolom edited full yakin maka => card edit bg warna merah aja
dan seterusnya sampe 0 kolom low dan 10 kolom edited full yakin maka => card edit bg warna putih
